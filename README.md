
# 🌊 Ocean Pearl Villa
### Dynamic Web-Based Coastal Villa and Room Booking System

Ocean Pearl Villa is a web-based villa management and room booking system designed to provide guests with a convenient way to explore rooms, check availability, and manage reservations.

## ✨ Features

### Guest Features
- Guest Registration and Login
- View Available Rooms
- Search Room Availability
- Book Rooms
- View My Bookings
- Cancel Pending Bookings
- View Booking Status

### Admin Features
- Admin Login
- Admin Dashboard
- Add, Edit and Delete Rooms
- Upload Room Images
- Manage Reservations
- Confirm and Cancel Bookings
- View Booking Information

### Booking Management
- Check Room Availability
- Prevent Duplicate Bookings
- Calculate Total Booking Price
- Validate Check-in and Check-out Dates
- Manage Booking Status

## ⚙️ Installation and Setup

1. Install WAMP Server.
2. Copy the OceanPearlVilla project folder into:

   `C:\wamp64\www\`

3. Start WAMP Server.
4. Open phpMyAdmin.
5. Create a database named:

   `ocean_pearl_villa`

6. Import the `db_structure.sql` file.
7. Configure the database connection in:

   `config/database.php`

8. Open the website in your browser:

   `http://localhost/OceanPearlVilla/`

## 🔐 User Roles

- **Guest:** Explore rooms and manage bookings.
- **Admin:** Manage rooms and reservations.
